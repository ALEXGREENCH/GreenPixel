# Атрибуция

Новая браузерная реализация GreenPixel Web: © 2026 Турбориум.
Лицензия исходного кода этой реализации: GNU GPL version 3, см. LICENSE.

Приложение написано заново на JavaScript. Исходный Pascal-код GreenPixel не
восстановлен и не включён в браузерную реализацию. Изображения, библиотеки DLL,
исполняемые файлы и другие ресурсы старой программы в веб-приложении не используются.

Исторический архив GreenPixel.zip доступен в истории Git (коммит 5b381f6).
В его readme.html указаны:

- ErrorSoft Green Pixel: Copyright © 2015–2016 ErrorSoft.
- Greenfish Icon Editor Pro: Copyright © 2007–2013 Balázs Szalkai.
- GPL version 3; отдельные лицензии libpng, OpenJPEG, zlib и компонентов UI.

По сообщению владельца проекта, автор разрешил новую реализацию и попросил
использовать название «Турбориум». Эта атрибуция относится к новой версии;
исторические сведения и лицензии сторонних компонентов сохраняются.
