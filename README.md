# GreenPixel Web · Турбориум

Браузерная пиксельная мастерская. © 2026 Турбориум.

Новая открытая реализация по мотивам GreenPixel. Исходники Pascal отсутствуют
в репозитории и, со слов автора, утрачены. [Исследование](docs/RECOVERY.md).

[Открыть редактор](https://alexgreench.github.io/GreenPixel/)

## Запуск

Нужен Node.js 20 или новее. Зависимостей нет, npm install не требуется.

```sh
npm start
```

Откройте http://127.0.0.1:4173. Другой порт задаётся переменной PORT.
Не открывайте index.html через file://: ES-модулям нужен HTTP-сервер.
Для статического хостинга нужны только index.html, styles.css и src/.
Работает в современных браузерах Windows, Linux и macOS.

## Возможности

- Карандаш, ластик, заливка, пипетка, линия и прямоугольная рамка.
- Кисти 1/2/4/8 px, палитра и произвольный цвет.
- До 32 слоёв: видимость, непрозрачность, порядок, имена и удаление.
- Отмена/повтор, сетка, масштаб и миниатюра.
- Холст от 1×1 до 512×512; мышь, перо и касание через Pointer Events.
- Импорт PNG/JPEG/WebP; экспорт PNG с прозрачностью в исходном размере.
- Проекты .greenpixel (JSON со слоями), локальный черновик.

Файлы не отправляются на сервер. Черновик хранится в localStorage и может
не сохраниться при превышении квоты браузера. Скачивайте важные работы
кнопкой «Сохранить проект». PNG объединяет видимые слои.

Клавиши: B/E/G/I/L/R — инструменты; Ctrl/Cmd+Z — отмена;
Ctrl/Cmd+Shift+Z или Ctrl+Y — повтор; Ctrl/Cmd+S — проект; Ctrl/Cmd+O — открыть.

## Ограничения

Это первая рабочая веб-версия, а не полный перенос настольного редактора.
GFIE, ICO/CUR/ANI/ICNS, анимация, выделение, текст и фильтры пока не реализованы.
Старые проекты GFIE напрямую не поддерживаются.

## Разработка

```sh
npm test
node --check src/app.js
```

Ядро без DOM: src/core.js. Браузерная оболочка: src/app.js.
Тесты: растеризация, заливка, смешивание, валидация проектов и история.
Сервер привязан к loopback и отдаёт только веб-файлы.
