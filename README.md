## Текущий этап

Классическая светлая оболочка, исходные значки 20 инструментов и стартового
экрана, вкладки документов, страницы, слои, выделения, плавающее выделение,
трансформации, текст, цветоподборщик и настройки. Добавлены 26 режимов смешивания,
19 фильтров с Worker-предпросмотром, анимация и библиотечный режим.

Кодеки: настоящий GFIE, .greenpixel v1/v2, ICO/CUR, ANI, GIF, ICNS, PNG,
JPEG, JPEG 2000, BMP, PCX, XPM. Реализованы RES и ресурсные таблицы PE32/PE32+
(ICL/EXE/DLL). Поддержка разновидностей форматов неполная — см. матрицу.
EXE/DLL обрабатываются как данные и выдаются новым файлом.

Это **не завершённая копия 1:1**. Точные параметры диалогов, графические результаты,
контекстные меню, ряд инструментальных параметров и старые форматы ещё требуют
проверки и доработки. Наличие команды не означает подтверждённого соответствия.

## Запуск

Node.js 20+, установка npm-пакетов не нужна:

```sh
npm start
```

Открыть `http://127.0.0.1:4173`. Порт задаётся переменной `PORT`.
Перед публикацией: `npm run build`. Для хостинга нужны `index.html`, `assets/`, `reference/`, `version.json`
и `.nojekyll`. ES-модули требуют HTTP; `file://` не поддерживается.

Документы не отправляются на сервер. Черновики — в IndexedDB, настройки —
в localStorage. Для надёжного хранения скачивайте GFIE или .greenpixel.
Растровые форматы могут терять слои, страницы и прозрачность.

## Проверки

```sh
npm test
node --check src/app.js
```

29 тестов: модель, история, маски, преобразования, палитры оригинала,
GFIE-деревья, BMP/PCX/XPM/GIF, ICNS, RES, PE, группы ICO/CUR.
Базовые проверки фильтров/смешивания не заменяют сравнение с оригиналом.
Браузерные проверки пока проводятся в Chromium; Firefox/Safari не проверены.

Прототип сохранён веткой `codex/backup-web-prototype` и коммитом `ef83503`.
GitHub Pages обновляется после проверок этапа.

## Обновления

Каждая сборка получает каталог `assets/<hash>/`; CSS, модули, Worker и переводы загружаются из одной версии. Проверка манифеста выполняется раз в минуту и при возвращении во вкладку. При несохранённых изменениях показывается предложение обновиться с сохранением черновика. Старый браузерный кэш не мешает новой сборке; IndexedDB не очищается.
